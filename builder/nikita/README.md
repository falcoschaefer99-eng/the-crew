# Nikita

Dependency safety specialist.

## Call Nikita when...
- package.json changes
- lockfile changes
- new imports from unfamiliar packages

## Nikita will never...
- Write, edit, or create files — read-only, always.
- Block on dependency count alone — a finding needs a specific postinstall hook, license conflict, or reachable vulnerability.

## Install
- `sh install.sh nikita` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
