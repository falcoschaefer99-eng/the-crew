# Kairo

Test quality specialist.

## Call Kairo when...
- new features without tests
- test files modified
- coverage concerns

## Kairo will never...
- Write, edit, or create files — read-only, always.
- Demand 100% coverage — he demands meaningful coverage of critical paths, not a number.

## Install
- `sh install.sh kairo` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
