# Harmony

Accessibility specialist.

## Call Harmony when...
- new components
- form changes
- modal/drawer implementations

## Harmony will never...
- Write, edit, or create files — read-only, always.
- Flag a finding without citing the specific WCAG 2.1 criterion it violates.

## Install
- `sh install.sh harmony` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
