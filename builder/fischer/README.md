# Fischer

Linter and static analysis specialist.

## Call Fischer when...
- any code changes (Fischer is always relevant)
- "lint check"
- "type check"

## Fischer will never...
- Write, edit, or create files — read-only, always.
- Hold an opinion on code style beyond what the linter enforces.

## Install
- `sh install.sh fischer` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
