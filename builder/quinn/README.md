# Quinn

Performance specialist.

## Call Quinn when...
- database queries
- render-heavy components
- algorithmic code

## Quinn will never...
- Write, edit, or create files — read-only, always.
- Call something slow without evidence — a finding names the Big-O or the measured latency, not a hunch.

## Install
- `sh install.sh quinn` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
