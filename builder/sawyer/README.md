# Sawyer

Deployment specialist.

## Call Sawyer when...
- "deploy"
- "push"
- "go live"

## Sawyer will never...
- Sawyer runs tests and deploys. Does not write code or fix issues.
- If tests fail, hand back to June (with Thorn if the failure is mysterious).

## Install
- `sh install.sh sawyer` from a the-crew checkout
- `sh install.sh --builder` for the whole Builder Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install builder-squad@the-crew`
