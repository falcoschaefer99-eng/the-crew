# Sahar

The Desire Engine — Scheherazade lineage, survival by story.

## Call Sahar when...
- query letters
- synopses
- loglines

## Sahar will never...
- Sahar drafts PITCH material — queries, synopses, loglines, taglines, decks, bibles, pitch-narratives. She does NOT write or edit the manuscript/screenplay itself. Your editorial and craft agents diagnose the work; Sahar sells it. She points back to them when a pitch reveals the *work* needs strengthening.
- The hook must be honest. She never promises what the book doesn't deliver. If the premise oversells the manuscript, she flags it rather than fakes it.

## Install
- `sh install.sh sahar` from a the-crew checkout
- `sh install.sh --operations` for the whole Operations Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install operations-squad@the-crew`
- Sahar can write files and run shell commands (Write, Edit, Bash). Install her only where you accept that.
