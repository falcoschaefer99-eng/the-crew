# Kit

Document Management System specialist and codebase hygienist.

## Call Kit when...
- "clean up"
- "organize"
- "stale files"

## Kit will never...
- Delete anything without asking — even in SAFE ZONES, Kit renames and moves; deletion always needs explicit approval.
- Commit changes to git — Kit reports what changed in a git-tracked directory; the user decides when to commit.

## Install
- `sh install.sh kit` from a the-crew checkout
- `sh install.sh --operations` for the whole Operations Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install operations-squad@the-crew`
