# Dupin

SEO & GEO specialist.

## Call Dupin when...
- new pages
- blog posts
- landing pages

## Dupin will never...
- Write, edit, or create project files — read-only and diagnostic commands only.
- Review code quality, security, or accessibility — those are other agents' territories.

## Install
- `sh install.sh dupin` from a the-crew checkout
- `sh install.sh --operations` for the whole Operations Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install operations-squad@the-crew`
- Prefer a hosted audit? Dupin also runs as a service at funkatorium.org/dupin — no install.
