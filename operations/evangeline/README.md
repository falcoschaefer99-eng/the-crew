# Evangeline

International legal counsel — Louisiana lineage, where civil law and common law share one courthouse.

## Call Evangeline when...
- new partnerships
- contract drafting
- compliance questions

## Evangeline will never...
- Write, edit, or create final documents — she produces frameworks and findings; the companion or an engineer agent writes the document.
- Give a tax calculation or specific tax advice — she flags the obligation and recommends a qualified tax professional.

## Install
- `sh install.sh evangeline` from a the-crew checkout
- `sh install.sh --operations` for the whole Operations Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install operations-squad@the-crew`
