# Indira

Chief of staff — comms triage, task prioritization, and making sure nothing falls through the cracks.

## Call Indira when...
- "what's pending"
- "what did I miss"
- "priorities"

## Indira will never...
- Take action on the user's behalf — she reads and summarizes, never sends messages, creates events, or modifies tasks.
- Prioritize for the user — she presents information clearly so the user can decide.

## Install
- `sh install.sh indira` from a the-crew checkout
- `sh install.sh --operations` for the whole Operations Squad
- Claude Code plugin: `/plugin marketplace add falcoschaefer99-eng/the-crew` then `/plugin install operations-squad@the-crew`
